# Simple Addition (การบวกเลขพื้นฐาน)

## โจทย์

จงเขียนฟังก์ชัน `add` ที่รับตัวเลขสองจำนวน `a` และ `b` 
และคืนค่าผลรวมของตัวเลขทั้งสอง

## ข้อกำหนด

- ฟังก์ชันต้องรับพารามิเตอร์ 2 ค่า
- คืนค่าผลบวกของตัวเลขทั้งสอง
- รองรับทั้งจำนวนเต็มและทศนิยม

## ตัวอย่าง

### ตัวอย่างที่ 1

```javascript
Input: a = 1, b = 1
Output: 2
Explanation: 1 + 1 = 2
```

### ตัวอย่างที่ 2

```javascript
Input: a = 5, b = 3
Output: 8
Explanation: 5 + 3 = 8
```

### ตัวอย่างที่ 3

```javascript
Input: a = 2.5, b = 1.5
Output: 4
Explanation: 2.5 + 1.5 = 4
```

## เคล็ดลับ

- ใช้ตัวดำเนินการ `+` ในการบวก
- โจทย์นี้เป็นพื้นฐานสำหรับการเริ่มต้น เขียนโค้ดให้ง่ายและชัดเจน
